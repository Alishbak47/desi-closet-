# Desi Closet

A dress-up game featuring Western and South Asian fashion, casual and formal outfits, customisable characters, hairstyles, hair colours, and makeup.

## Play

https://desi-closet-studio.s59mx4gnrx.chatgpt.site

## Run locally

No installation or build is required. With Python installed, run:

```sh
python -m http.server 8000 --directory dist
```

Then open http://localhost:8000.

## Stable version 1

- Optional character name, blank by default
- Four characters and independently selectable skin tones
- Face shape, eye shape, nose and lip controls
- Twelve Western and South Asian outfits in formal and casual categories
- Four fitted hairstyles, six hair colours plus natural
- Lipstick, blush and eyeshadow

Artwork is included as WebP assets for a compact, standalone copy.
